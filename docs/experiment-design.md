# Experiment Design

### X axis

Varying "maximum amount of rows per partition" from 2^1=2 to 2^18=262.144.
It will be a log scale, doubling for every run.

### Y axis

We will measure the time it takes to retrieve a single row based on a unique id on the row.
A measurement of the `durationMs` value.

### Procedure

We will use the exact same data for all runs. It will be 1M rows generated by a python script that uses a number generator that takes a seed (the seed will be 67). The columns of the data will be (id long, name string, random-number double). The id will be an increasing long from 1 to 1M. We will double the partition size for run/data point. 

We will run the engine by packaging the program with `mvn package`, then using the `./engine.sh` script to run the program with the test queries.

The query used will be of the following form: `SELECT * FROM tableName WHERE 'unique id of row';`

We will use the median time of 5 runs in the graph. The first run will be cold, subsequent runs will be hot.
